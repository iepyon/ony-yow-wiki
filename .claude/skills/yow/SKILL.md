# /yow — YOW を1行記録する

共通規約は [CLAUDE.md](../../../CLAUDE.md)。ここには固有の手順だけを書く。

## 手順

1. **未検証の ONY を探す** — 今週（必要なら先週も）の journal から、
   `ony` 行があって同じ `#NN` の `yow` 行が無いものを列挙して見せる。
   ユーザーが番号で選ぶ。該当が無ければ、単発の YOW として新しい `#NN` を採番してよい。
2. **元の ONY 行を逐語で提示する** — 特に **O2（起きそうなこと）をそのまま見せる**。
   これが予測の凍結。**O2 を要約・言い換え・修正しない。**
3. **聞く** — Y（やったこと）/ O（起きたこと）/ W（分かったこと）。
   - O は観測された事実。O2 との一致・不一致を**ユーザー自身に言わせる**（こちらが判定しない）
   - W は自由記述（規律を課さない）。ただし O2 と O が食い違ったのに W が
     事前の見立てのままなら、「食い違いは W に反映しなくていいですか」と**1回だけ**聞く
4. **追記** — 選んだ `#NN` を使い、journal 末尾に1行:
   ```
   - <YYYY-MM-DDTHH:MM> #<NN> yow <活動> | Y:… / O:… / W:…
   ```
   活動は通常 `検証`（違うと言われたらそれに従う）。**過去行に触らない。**
5. **締め** — ONY 行と YOW 行を並べて見せる。価値がありそうなら
   「`/promote <年>-W<週>#<NN>` で昇格できます」と1行添える（勧めるだけ。決めるのは人）。

## してはいけないこと

- **O2 の書き換え**（journal のどの行も編集しない）
- O2 と O の一致判定の代行（気づきはユーザーのもの）
- W の質への駄目出し・falsifier の要求
