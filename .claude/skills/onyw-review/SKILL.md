# /onyw-review — 3観点で PR にコメントする

共通規約は [CLAUDE.md](../../../CLAUDE.md)。引数: PR 番号。

レビューの目的は**判定ではなく、本人が気づくこと**（A3 のキャッチボール）。
指摘は問いの形にし、**代案なき批判をしない**（yusaburi の制約を引き継ぐ）。
W の記入を block しない — 問うだけ。

## 手順

1. **材料を集める**
   ```bash
   gh pr diff <番号>                      # 追加されたスライド
   gh pr view <番号> --json body          # /promote が貼った journal 逐語
   ```
   スライドの `<!--id:YYYYMMDD-NN-->` から該当週を割り出し、
   `journal/eiji-<年>-W<週>.md` と、その**改変履歴**を取る:
   ```bash
   git log -p --follow journal/eiji-<年>-W<週>.md
   ```
   （journal は追記専用だが強制フックは無い。過去行の書き換えは git 履歴にしか残らない）

2. **3観点をサブエージェントに並列で投げる**（1メッセージで3つ起動）。
   各エージェントには スライド本文・journal の該当2行・観点別の下敷き資料のパスを渡し、
   「指摘は最大3件・各1〜2文・必ず問いか代替案を添える・該当なしなら『指摘なし』」と指示する。

   | # | 観点 | 下敷き（エージェントに読ませる） | 見るもの |
   |---|---|---|---|
   | ① | **バイアスに気づかせる** | `/Users/eiji/src/claude-skills/yusaburi/references/cognitive-biases.md` | **後知恵**: スライドの O2 が journal の逐語と一致するか。git 履歴に過去行の改変が無いか／**確証**: O が N に都合よく選ばれていないか（summary.md §2.2「判断に影響する事実」）／**利用可能性**: 直近の目立つ出来事だけを O にしていないか |
   | ② | **因果のつながりの弱さ** | `/Users/eiji/src/claude-skills/yusaburi/references/critical-thinking-frameworks.md` と `origin/summary.md` §8.2 | W は Y→O の**メカニズム**を説明しているか（相関の言い換えでないか）／**逆因果**（p208: 推論の順序をそのまま因果と認識していないか）／**交絡**（p209: 共通の原因の見落とし）／O2 と O の食い違いが W に反映されているか |
   | ③ | **別の選択肢の提示** | `origin/summary.md` §6・§8.3・§8.4 | **「ひとつ外すなら?」**（p228: Y は最小十分か。過剰な要素は無いか）／`N←Y`（p242: この N に対して他の Y は検討したか）／引き算診断（p150: この記述は (活動,欠落) の表でどれかに退化していないか） |

3. **集約して1コメントに** — 3つの結果を観点別の見出しでまとめ、重複を削る。
   冒頭に1行の総評（良い点を1つ具体的に）。指摘ゼロの観点は「指摘なし」と明記。

   ```bash
   gh pr comment <番号> --body "<集約したコメント>"
   ```

   コメントの型:
   ```markdown
   ## /onyw-review

   <総評1行>

   ### ① バイアス
   - <指摘 + 問い>（最大3件）

   ### ② 因果のつながり
   - …

   ### ③ 別の選択肢
   - …
   ```

4. **後知恵の疑いが濃い場合**（O2 の不一致・journal 改変の痕跡）は、観点①の先頭に
   `⚠` を付けて **事実（差分）だけを引用**する。断罪しない — 「journal では『…』、
   スライドでは『…』になっています。どちらが事前の予測ですか」の形で問う。

## してはいけないこと

- 承認・却下の判定（マージするかは本人が決める）
- スライドや journal の直接修正
- 3観点の外の一般的な文章添削（レビューの焦点を薄めない）
- yusaburi スキル本体の呼び出し（references のみ再利用。出力規約が PR コメントに合わない）
