# /onyw-review — 3観点で PR にコメントする

共通規約は [CLAUDE.md](../../../CLAUDE.md)。引数: PR 番号。

レビューの目的は**判定ではなく、本人が気づくこと**（A3 のキャッチボール）。
指摘は問いの形にし、**代案なき批判をしない**（yusaburi の制約を引き継ぐ）。
W の記入を block しない — 問うだけ。

## 手順

1. **材料を集める**
   ```bash
   gh pr diff <番号>                      # 日次 PR: カードとデッキ差分 / 週締め PR: stable 化差分
   gh pr view <番号> --json body,title    # /ony /close-week が貼った逐語
   ```
   対象ループの ID（日次 PR は差分の raw/ から、週締め PR は週デッキから）を拾い、
   各カードと**改変履歴**を取る:
   ```bash
   cat raw/ony/<ID>.md raw/yow/<ID>.md
   git log -p --follow raw/ony/<ID>.md    # 対の YOW 作成後に O2 等が書き換えられていないか
   git log --format='%ai %s' -- raw/ony/<ID>.md raw/yow/<ID>.md   # ony が yow より先か
   ```
   （ONY の凍結は強制フックで守られていない。担保は git 履歴のみ）

2. **3観点をサブエージェントに並列で投げる**（1メッセージで3つ起動）。
   各エージェントには 対象ループのカード2枚（ony/yow）の本文・git 履歴の要点・観点別の下敷き資料のパスを渡し、
   「指摘は最大3件・各1〜2文・必ず問いか代替案を添える・該当なしなら『指摘なし』」と指示する。

   | # | 観点 | 下敷き（エージェントに読ませる） | 見るもの |
   |---|---|---|---|
   | ① | **バイアスに気づかせる** | [references/cognitive-biases.md](../../../references/cognitive-biases.md) | **後知恵**: ONY カードのコミットが YOW より先か。YOW 作成後に ONY カード（特に O2）が改変されていないか（`git log -p`）／**確証**: O が N に都合よく選ばれていないか（summary.md §2.2「判断に影響する事実」）／**利用可能性**: 直近の目立つ出来事だけを O にしていないか |
   | ② | **因果のつながりの弱さ** | [references/critical-thinking-frameworks.md](../../../references/critical-thinking-frameworks.md) と `origin/summary.md` §8.2 | W は Y→O の**メカニズム**を説明しているか（相関の言い換えでないか）／**逆因果**（p208: 推論の順序をそのまま因果と認識していないか）／**交絡**（p209: 共通の原因の見落とし）／O2 と O の食い違いが W に反映されているか |
   | ③ | **別の選択肢の提示** | `origin/summary.md` §6・§8.3・§8.4 | **「ひとつ外すなら?」**（p228: Y は最小十分か。過剰な要素は無いか）／`N←Y`（p242: この N に対して他の Y は検討したか）／引き算診断（p150: この記述は (活動,欠落) の表でどれかに退化していないか） |

3. **集約して1コメントに** — 3つの結果を観点別の見出しでまとめ、重複を削る。
   冒頭に1行の総評（良い点を1つ具体的に）。指摘ゼロの観点は「指摘なし」と明記。

   ```bash
   gh pr comment <番号> --body "<集約したコメント>"
   ```

   コメントの型:
   ```markdown
   ## /onyw-review

   <総評1行>

   ### ① バイアス
   - <指摘 + 問い>（最大3件）

   ### ② 因果のつながり
   - …

   ### ③ 別の選択肢
   - …
   ```

4. **後知恵の疑いが濃い場合**（YOW 作成後の ONY カード改変・ony/yow のコミット順の逆転）は、
   観点①の先頭に `⚠` を付けて **事実（git の差分・日時）だけを引用**する。断罪しない —
   「ONY カードは YOW の後に変更されています。どちらが事前の予測ですか」の形で問う。

## してはいけないこと

- 承認・却下の判定（マージするかは本人が決める）
- カードや生成デッキの直接修正
- 3観点の外の一般的な文章添削（レビューの焦点を薄めない）
- 一般的な文章添削の混入（下敷きは references/ にコピー済みの2ファイルと origin/summary.md のみ）
