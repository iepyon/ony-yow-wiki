# /ony — 朝の ONY カードを作る

共通規約は [CLAUDE.md](../../../CLAUDE.md)、カードの型と診断表の正本は
[ontology.yaml](../../../ontology.yaml)。ここには固有の手順だけを書く。

## 手順

1. **ID と日時** — `date +%Y-%m-%dT%H:%M` で日時を取り、ID は `YYYYMMDD-NN`
   （NN = `raw/ony/` の同日ファイルの最大+1、ゼロ詰め2桁）。
2. **聞く** — ユーザーの発話から埋め、足りない要素だけ1つずつ短く聞く（全体1〜2分・p160）:
   - O: 判断に影響する観察された事実 ／ N: 実現したい**状態** ／ Y: **自分たちが実行可能**な行動
   - O2: 起きそうなこと。**任意だが、無いと後知恵の検査が効かないと1行だけ伝える**
   - **活動が「提案」なら `## 相手O` `## 相手N` も聞く**（原典 §5）
   - title: スライドの見出しになる一文（ユーザーの言葉から要約して提案）
3. **6活動を1語選ばせる** — `観察 / 仮説立案 / 実行 / 計画 / 提案`（検証は `/yow`）。
   実行は途中経過の記録として受ける。推定して提案してよいが、**決めるのはユーザー**。
4. **カード作成** — `templates/ony.md` から `raw/ony/<ID>.md` を作る。
5. **lint と診断** — `uv run --with pyyaml --no-project python3 tools/oylint.py` を走らせる。
   info（引き算診断）が出たら**そのまま1行で伝える**（例: 「〈計画〉で O が空 → 机上の空論。
   このまま記録もできます」）。**記録は止めない**（p152）。error は直してから進む。
6. **デッキ再生成** — `uv run --with pyyaml --no-project python3 tools/gen_deck.py`
   （全カードは週デッキに自動掲載される。cards も wiki の一種）。
7. **即・単独コミット**:
   ```bash
   git add raw/ony/<ID>.md wiki/ && git commit -m "ony: <ID> <title>"
   ```
   YOW と**別コミット**であることが「予測を先に書いた」ことの唯一の証明。push は日次でよい。
8. **確認** — カードのパスと、週デッキ上のスライドを見せて終わる。

## してはいけないこと

- 既存カードの編集（このスキルは新規作成のみ）
- 6活動の自動確定（提案まで。選ぶのは人）
- W への駄目出し（規律を課さない）
- 週次サマリーの手修正（生成物）・週締め（それは `/close-week`）
