# /ony — ONY を1行記録する

共通規約は [CLAUDE.md](../../../CLAUDE.md)（journal 行形式・6活動・引き算診断表・ISO週）。
ここにはこのスキル固有の手順だけを書く。

## 手順

1. **今週の journal を特定する** — 今日の ISO 週（月曜開始）から
   `journal/eiji-<年>-W<週>.md` を決める。無ければ CLAUDE.md の形式でヘッダから作る。
2. **聞く** — ユーザーの発話から O / N / Y / O2 を埋める。足りない要素だけを1つずつ短く聞く。
   長い対話にしない（目標: 全体で1〜2分。原典 p160）。
   - O: 判断に影響する観察された事実（summary.md §2.2）
   - N: 実現したい**状態**（行動ではなく）
   - Y: **自分たちが実行可能**な行動
   - O2: Y の結果として起きそうなこと。**任意だが、無いと後知恵の検査が効かないと1行だけ伝える**
   - W（分かりそうなこと）: 任意。聞かない（言われたら書く）
3. **6活動を1語選ばせる** — `観察 / 仮説立案 / 実行 / 検証 / 計画 / 提案`。
   推定して提案してよいが、**決めるのはユーザー**。
4. **引き算診断** — CLAUDE.md の表を `(活動, 欠落要素)` で引き、該当したら診断名を1行返す
   （例: 「O が空です — 計画から O を除くと**机上の空論**（p150）。このまま記録もできます」）。
   **記録は止めない**。診断は分類であって禁止ではない（p152）。
5. **追記** — 週内連番 `#NN` を既存行の最大+1で採番し、journal の末尾に1行 Edit で足す:
   ```
   - <YYYY-MM-DDTHH:MM> #<NN> ony <活動> | O:… / N:… / Y:… / O2:…
   ```
   **過去行に触らない。**
6. **確認** — 追記した行をそのまま見せて終わる。コミットはしない（ユーザーが日次でまとめる）。

## してはいけないこと

- 過去行の編集・並べ替え・整形
- 6活動の自動確定（提案まで。選ぶのは人）
- W の内容への駄目出し（規律を課さない — CLAUDE.md「W に規律を課さない」）
- スライドの生成（それは `/promote`）
